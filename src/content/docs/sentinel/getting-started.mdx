## Requirements

- Python **3.12** (pinned via `.python-version`)
- [uv](https://docs.astral.sh/uv/) for dependency management
- A reachable PostgreSQL (local, Docker, or Supabase pooler URL)
- Node.js 18+ (for the frontend)

## Install Backend

```bash
git clone <repo-url> Sentinel
cd Sentinel
uv sync
```

## Configure

```bash
cp .env.example .env
```

| Variable | Purpose |
|----------|---------|
| `DB_URL` | SQLAlchemy PostgreSQL URL (Supabase-ready, sslmode=require) |
| `FRED_API_KEY` | FRED macro data |
| `NEWSDATA_API_KEY` | News ingestion |
| `FINNHUB_API` | Finnhub (for hermes-plt) |
| `OPENSANCTIONS_API` | OpenSanctions (for hermes-plt) |
| `SEC_USERNAME` / `SEC_EMAIL` | SEC EDGAR (for hermes-plt) |
| `MLFLOW_URI` | MLflow tracking URI (default `http://localhost:5000`) |
| `LOG_LEVEL` | INFO / DEBUG / WARNING (default INFO) |
| `SMTP_SERVER/PORT/USER/PASSWORD` | Email drift alerts |
| `SLACK_WEBHOOK_URL` | Slack drift alerts |

## Initialize Schema

Option A — Supabase: paste `database/schema.sql` then `database/seed_data.sql` into the SQL Editor.

Option B — any Postgres:

```bash
psql "$DB_URL" -f database/schema.sql && psql "$DB_URL" -f database/seed_data.sql
```

## Run

```bash
stl all    # ingest → train → start API
```

Or individually:

```bash
stl ingest
stl ml-train
stl api-start
```

## Install Frontend

```bash
cd web
npm install
npm run dev    # http://localhost:5173 (proxies /api/* to :7860)
```
