## Project Layout

| Path | Responsibility |
|------|----------------|
| `api/` | FastAPI app factory, CORS, Pydantic schemas, 7 routers (v1) |
| `web/` | React 19 + Vite 8 + TypeScript SPA (deployed separately) |
| `cli/` | Typer CLI (`stl`) — ingest, ml-train, api-start, all |
| `ingestion/` | Data collection: price, crypto, macro, news, analysis fetchers + feature engineer |
| `ml/` | Anomaly detection, forecasting, sentiment, portfolio optimization, feature store, model registry |
| `mlops/` | Drift detection (PSI + KS) with Slack/email alerts |
| `scheduler/` | Job runner (not yet integrated) |
| `database/` | SQLAlchemy models, CRUD, `schema.sql` + `seed_data.sql` |
| `config/` | Settings + JSON logging |

## Runtime Flow

1. **Ingest** — `stl ingest` pulls OHLCV, crypto, macro, news, and analysis data into PostgreSQL.
2. **Train** — `stl ml-train` fits anomaly/forecast/sentiment models and registers them in MLflow.
3. **Serve** — `stl api-start` runs uvicorn on port 7860; frontend runs separately via Vite or is deployed to Render.

## CLI (`stl`)

| Command | Action |
|---------|--------|
| `stl ingest` | Run full ingestion pipeline |
| `stl ml-train` | Run full training pipeline |
| `stl api-start` | Start uvicorn (port 7860) |
| `stl all` | Ingest → Train → Start API |
