**Stack:** Python 3.11 · FastAPI · Dash · PostgreSQL · PyOD · Prophet · XGBoost · FinBERT · MLflow

## What It Does

Sentinel ingests financial data from multiple public sources, engineers features, trains and serves ML models (anomaly detection, forecasting, sentiment), and exposes everything through a REST API and an interactive dashboard.

It is built to run as a **single container** — FastAPI serves the API and mounts Dash via WSGI — backed by any PostgreSQL, including Supabase's hosted Postgres, which makes it deployable on free-tier platforms with ephemeral storage.

## What's Real

Every pipeline, model, endpoint, and dashboard page listed in these docs runs today:

| Area | What's implemented |
|------|--------------------|
| Ingestion | Stocks (yfinance), crypto (CCXT), macro (FRED), news (newsdata.io) + FinBERT sentiment |
| Feature engineering | Log returns, lags, rolling stats, RSI, Bollinger %B, volume ratios |
| Anomaly detection | Isolation Forest + LOF (PyOD), written to DB with severity labels |
| Forecasting | Prophet + XGBoost with walk-forward cross-validation (30/90-day horizons) |
| Sentiment | FinBERT scoring of news headlines |
| Portfolio | Risk-constrained weight allocation via scipy |
| MLOps | PSI + Kolmogorov–Smirnov drift detection with email/Slack alerts |
| Model tracking | MLflow registry with metrics, params, and artifacts |
| Dashboard | 5 pages: Market Overview, Anomalies, Forecasts, Portfolio, Sentiment |
| API | OpenAPI/Swagger at `/api/docs`, routers for prices, anomalies, forecasts, sentiment, portfolio |

## Design Choices

- **One process, one port.** No docker-compose, no separate services. PostgreSQL is the only external dependency.
- **CLI-driven orchestration.** Ingestion and training are `python -m ...` commands; Airflow DAGs under `airflow/` are legacy and no longer used.
- **Environment-driven configuration.** Everything lives in `config/settings.py`, read from `.env`.
