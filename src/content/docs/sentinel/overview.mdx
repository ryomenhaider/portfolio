**Stack:** Python 3.12 · FastAPI · React 19 · PostgreSQL · PyOD · Prophet · XGBoost · FinBERT · MLflow

## What It Does

Sentinel ingests financial data from multiple public sources, engineers features, trains and serves ML models (anomaly detection, forecasting, sentiment), and exposes everything through a REST API and a Bloomberg-style React dashboard.

The **backend** is a single FastAPI process backed by PostgreSQL (SQLAlchemy 2.0). The **frontend** is a decoupled React SPA served separately.

## What's Real

Every pipeline, model, endpoint, and dashboard page listed in these docs runs today:

| Area | What's implemented |
|------|--------------------|
| Ingestion | Stocks (yfinance), crypto (CCXT), macro (FRED), news (newsdata.io) + FinBERT sentiment |
| Analysis data | Technical (86 fields) + Fundamental (71 fields) via hermes-plt |
| Feature engineering | Log returns, lags, rolling stats, RSI, Bollinger %B, volume ratios |
| Anomaly detection | Isolation Forest + LOF (PyOD), written to DB with severity labels |
| Forecasting | Prophet + XGBoost with walk-forward cross-validation (30/90-day horizons) |
| Sentiment | FinBERT scoring of news headlines |
| Portfolio | MPT, Black-Litterman, Kelly Criterion, Blended optimization |
| MLOps | PSI + Kolmogorov–Smirnov drift detection with email/Slack alerts |
| Model tracking | MLflow registry with metrics, params, and artifacts |
| Dashboard | 7 React pages: Overview, Anomalies, Forecasts, Technical, Fundamental, Portfolio, Sentiment |
| API | REST API at `/api/v1/`, OpenAPI docs at `/api/docs` |
| CLI | `stl` — ingest, ml-train, api-start, all |

## Design Choices

- **Decoupled frontend.** React SPA on its own domain, API on another. CORS fully open for development.
- **hermes-plt integration.** Technical and fundamental analysis pull from the Hermes library for deep market data.
- **CLI-driven orchestration.** Ingestion and training are `stl` commands; no scheduler yet.
- **Environment-driven configuration.** Everything lives in `config/settings.py`, read from `.env`.
