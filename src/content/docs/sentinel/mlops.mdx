## What It Does

Runs statistical tests per feature against a rolling baseline, catching distribution shifts before they degrade model performance.

## Windows

| Window | Days | Purpose |
|--------|------|---------|
| Baseline | 180 days | Reference distribution |
| Production | 30 days | Current distribution |

## Monitored Features (11)

| Feature | Description |
|---------|-------------|
| `log_return` | Daily log return |
| `lag_1d` | 1-day lag |
| `lag_5d` | 5-day lag |
| `lag_21d` | 21-day lag |
| `lag_63d` | 63-day lag |
| `rolling_mean_21` | 21-day rolling mean |
| `rolling_std_21` | 21-day rolling std |
| `rolling_skew_21` | 21-day rolling skew |
| `rsi_14` | RSI(14) |
| `bb_pct_b` | Bollinger %B |
| `volume_ratio` | 20-day volume ratio |

## Statistical Tests

| Test | Threshold | Trigger |
|------|-----------|---------|
| PSI (Population Stability Index) | > 0.2 | Drift alert |
| KS (Kolmogorov–Smirnov) | p-value below 0.05 | Distribution shift |

## Alerting

Drift triggers **email + Slack alerts** with detailed reports:

- **Email:** HTML-formatted, includes drifted features, PSI values, baseline vs production means
- **Slack:** Block Kit formatting via webhook

## CLI

```bash
python mlops/drift_detector.py --tickers AAPL,MSFT --send-alerts
```

- Exit code 1 if drift detected (CI-friendly), 0 if stable
