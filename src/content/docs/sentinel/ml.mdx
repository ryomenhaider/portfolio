**Files:** `ml/`

## Anomaly Detection

`anomaly_detector.py` — Isolation Forest + Local Outlier Factor (PyOD ensemble).

- **Features:** log_return, volume_ratio, rolling_std_21, rsi_14, bb_pct_b
- **Contamination:** 5% expected anomalies
- **Process:** StandardScaler → IForest (100 estimators) + LOF (20 neighbors) → MinMax-normalize and average → severity labels (≥0.8 critical, ≥0.6 high, ≥0.4 medium, below 0.4 low)
- **Default tickers:** AAPL, MSFT, NVDA, TSLA, GOOGL

## Forecasting

`forecaster.py` — Prophet + XGBoost blended 50/50.

- **Horizons:** 30 days and 90 days
- **XGBoost features:** lag_1d, lag_5d, lag_21d, lag_63d, rolling_mean_21, rolling_std_21, rsi_14, volume_ratio, bb_pct_b
- **Cross-validation:** Walk-forward CV (5 splits), MAE + RMSE
- **Blending:** Simple average of Prophet yhat and XGBoost predictions

## Sentiment Analysis

`sentiment_engine.py` — aggregates historical sentiment scores.

- Daily averages with 7-day and 30-day rolling means
- Signal: 7d > 30d = BULLISH, 7d below 30d = BEARISH, else NEUTRAL
- Note: FinBERT scoring happens in ingestion, not here

## Portfolio Optimization

`portfolio_optimizer.py` — four allocation methods:

| Method | Description |
|--------|-------------|
| MPT | Mean-Variance Optimization — minimizes negative Sharpe via scipy SLSQP, long-only |
| Black-Litterman | Sentiment scores as investor views (scaled 0.05), equal-weight implied returns |
| Kelly Criterion | Fractional Kelly based on win rate and payoff ratio, clipped non-negative |
| Blended | 40% MPT + 40% BL + 20% Kelly |

**Tickers:** AAPL, MSFT, NVDA, TSLA, GOOGL. **Risk-free rate:** 5%, 252 trading days.

`model_registry.py` — MLflow integration: save, load, promote models with metrics/params/artifacts tracked per run.

## Training Pipeline

```bash

```

Two modes:
- `run_pipeline()` — basic: warmup → anomalies → forecasting → sentiment → portfolio
- `run_pipeline_with_metrics()` — enhanced: collects CV metrics, logs to MLflow (enabled via `WITH_METRICS=true`)
