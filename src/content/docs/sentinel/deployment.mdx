## Backend

The backend runs as a single uvicorn process on **Render free-tier** (`https://sentinel-ggi8.onrender.com`).

- No Dockerfile — Render auto-detects Python and runs `uvicorn api.main:app`
- Health check on `/api/health`
- JSON logging with rotating file handler (fails silently on read-only containers)

## Frontend

The React SPA is deployed separately on **Render** as a static site.

- Built with `npm run build` → `dist/`
- In development: Vite dev server at `:5173` with proxy to backend at `:7860`
- In production: hits `VITE_API_URL` directly

## Database

PostgreSQL is the only external dependency. Any of these work:

- Local Postgres
- Docker container
- Supabase hosted Postgres (pooler URL, sslmode=require)

All state lives in Postgres — ephemeral filesystem storage is fine for free-tier deployments.

## Configuration

All config is environment-driven (`config/settings.py`, `.env`):

| Variable | Purpose |
|----------|---------|
| `DB_URL` | SQLAlchemy PostgreSQL URL |
| `FRED_API_KEY` | FRED macro data |
| `NEWSDATA_API_KEY` | News ingestion |
| `FINNHUB_API` | Finnhub (for hermes-plt) |
| `OPENSANCTIONS_API` | OpenSanctions (for hermes-plt) |
| `SEC_USERNAME` / `SEC_EMAIL` | SEC EDGAR (for hermes-plt) |
| `MLFLOW_URI` | MLflow tracking URI |
| `SMTP_*` | Email drift alerts |
| `SLACK_WEBHOOK_URL` | Slack drift alerts |
