## Requirements

- Python **>= 3.11**
- [uv](https://docs.astral.sh/uv/) for dependency management

## API Keys

| Service | Key | Purpose |
|---------|-----|---------|
| [OpenSanctions](https://www.opensanctions.org/) | `opensanction_api` | Sanctions lists (OFAC, EU, UK, UN) |
| [FRED](https://fred.stlouisfed.org/docs/api/api_key.html) | `fred_api` | 23 US economic series |
| [Finnhub](https://finnhub.io/) | `finnhub_api` | Stock fundamentals, candles, profiles |
| SEC EDGAR | `sec_username` + `sec_email` | Company facts via XBRL (free, register at EDGAR) |
| [NewsData](https://newsdata.io/) | `new_data_api` | News ingestion (wired, no connector yet) |

## Installation

```bash
git clone <repo-url> Hermes
cd Hermes
uv sync --extra dev
```

## Quick Start

```python
import asyncio
from hermes import Hermes

async def main():
    hr = Hermes(
        opensanction_api="your-key",
        new_data_api="",
        fred_api="your-key",
        sec_username="your-username",
        sec_email="you@example.com",
        finnhub_api="your-key",
    )

    # Country risk snapshot
    risk = await hr.country_features.get_country_risk_features("USA")
    print(risk["economic"]["gdp_growth_yoy"])

    # List all supported countries
    print(len(hr.list_countries))  # ~250

    # Direct connector usage
    df = await hr.world_bank.fetch("NY.GDP.MKTP.KD.ZG", "USA", 2010, 2024)
    print(df.head())

asyncio.run(main())
```
