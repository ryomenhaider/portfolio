**File:** `sources/imf.py`

## What It Does

Fetches data from the IMF SDMX 3.0 API (`api.imf.org/external/sdmx/3.0`). Supports three dataflows: International Financial Statistics (IFS), World Economic Outlook (WEO), and Government Finance Statistics (GFS).

## Fetch

```python
df = await hr.imf.fetch(
    dataflow="IFS",          # or "WEO" or "GFS"
    key="M..IX.._T",         # SDMX key pattern
    start_period=2010,
    end_period=2024,
)
```

## Output Columns

| Column | Type | Description |
|--------|------|-------------|
| `date` | datetime | Observation date |
| `indicator_id` | str | IMF indicator code (e.g. `PPI.IX.A`) |
| `country` | str | ISO2 country code (auto-converted from ISO3) |
| `value` | float | Indicator value |
| `source` | str | `"imf"` |

## Key Indicators

| Dataflow | Code | Name | Used In |
|----------|------|------|---------|
| IFS | `PPI.IX.A` | Producer Price Index | `ppi_yoy` feature |
| IFS | `CPI._T.IX.M` | Consumer Price Index | `inflation_yoy` feature |
| IFS | `EREER_IX.M` | Effective Exchange Rate | `reer_misalignment` feature |
| WEO | `GGXCNL_NGDP` | Fiscal Deficit (% GDP) | `fiscal_deficit_gdp` feature |
| WEO | `GGXWDG_NGDP` | Government Debt (% GDP) | `government_debt_gdp` feature |

## Notes

- ISO3 → ISO2 conversion handled automatically via `pycountry`
- 404 responses return empty DataFrame (no error)
- 7-day cache TTL
