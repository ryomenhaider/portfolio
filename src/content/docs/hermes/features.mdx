## Country Risk Features

**Files:** `features/country_risk_features/`

58 features across 5 groups, each decorated with `@feature` and registered in a lineage graph.

### Feature Groups

| Group | Count | Key Sources |
|-------|-------|-------------|
| Economic | 18 | World Bank, IMF |
| Geopolitical | 21 | GDELT, OpenSanctions, World Bank, bundled datasets |
| Security | 7 | SIPRI, NATO |
| Social | 6 | HRS, FSI, HDI, World Bank |
| Environmental | 6 | NDGAIN, World Bank |

### Dual-Mode Interface

Every feature function follows this signature:

```python
async def feature_name(country_code: str, mode: Literal["F", "ML"]) -> float | pd.Series
```

| Mode | Returns | Use Case |
|------|---------|----------|
| `"F"` | Scalar (float, int, str, bool) | Dashboards — latest value |
| `"ML"` | Monthly `pd.Series` with DatetimeIndex | ML training — time-series panel |

Missing data returns `np.nan` (`"F"`) or empty `pd.Series` (`"ML"`) — never raises.

### Snapshot

```python
risk = await hr.country_features.get_country_risk_features("USA")
# {"country": "USA", "economic": {...}, "geopolitical": {...}, ...}
```

### Training Panel

```python
panel = await hr.country_features.build_training_panel(
    fns=hr.list_features[:5],
    countries=["USA", "GBR", "DEU"],
)
# pd.DataFrame with MultiIndex(country_iso3, date)
```

### Feature Decorator

Features are registered via `@feature(name, group, deps, compute)` in `core/feature_decorator.py`. The `LineageGraph` singleton tracks dependencies and resolves execution order via topological sort into tiers (`TieredPlan`).

## Technical Analysis

**File:** `features/analysis/technical.py`

`TAfeatures` computes an 86-field `TechnicalSnapshot` from Binance data:

```python
ta = await hr.ta_feature.get_technical("BTCUSDT")
ta.trend_score      # composite trend score
ta.rsi_14           # RSI(14)
ta.bid_ask_spread   # order book spread in bps
```

See [Technical Features](/hermes#technical-analysis) for the full field list.

## Fundamental Analysis

**File:** `features/analysis/fundamental.py`

`FAfeatures` computes a 71-field `CompanyFundamental` from Finnhub, SEC EDGAR, FRED, and Yahoo Finance:

```python
fa = await hr.fa_features.get_fundamentels("AAPL")
fa.pe_ratio         # P/E ratio
fa.revenue          # latest revenue
fa.gdp_growth       # macro context
```

See [Fundamental Features](/hermes#fundamental-analysis) for the full field list.
