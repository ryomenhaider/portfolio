## What It Does

Queries the GDELT Doc API v2 for global event data — conflict events, protests, diplomacy, and sanctions activity. Includes FIPS-to-ISO3 normalization and rate limiting.

## Fetch

```python
df = await hr.gdelt.query_events(
    theme="CONFLICT",         # CONFLICT, PROTEST, DIPLOMACY, SANCTIONS
    country="USA",
    start_date="2024-01-01",
    end_date="2024-03-01",
)
```

## Output Schema

| Column | Type | Description |
|--------|------|-------------|
| `event_id` | str | GDELT event identifier |
| `date` | datetime | Event date |
| `country_iso3` | str | ISO3 country code (FIPS-normalized) |
| `event_type` | str | CONFLICT, PROTEST, DIPLOMACY, or SANCTIONS |
| `severity` | float | Event severity score |
| `lat` | float | Latitude |
| `lon` | float | Longitude |
| `source` | str | Always `"gdelt"` |

## Theme Mapping

| Theme | GDELT Event Types | Features |
|-------|-------------------|----------|
| CONFLICT | ASSAULT, FIGHT,Military action | conflict_event_count, battle_deaths, goldstein_scale |
| PROTEST | PROTEST, RIOT, peaceful protest | protest_event_count, protest_violence_level |
| DIPLOMACY | Diplomatic meetings, treaties | diplomatic_event_count, diplomatic_intensity |
| SANCTIONS | Sanctions-related events | sanctions_count_active, sanctions_new_30d |

## Rate Limiting

- 5-second minimum between GDELT calls
- Session-level in-memory cache for repeated queries
- Health check pings Doc API before issuing queries

## Cache

6-hour TTL (shorter than other sources — GDELT data updates frequently).
