## What It Does

Provides the Transparency International Corruption Perception Index (CPI) as a bundled CSV. No network requests — ships with the package.

## Fetch

```python
df = await hr.datasets.fetch(dataset="cpi", country="USA")
```

## Output Columns

| Column | Type | Description |
|--------|------|-------------|
| `date` | datetime | Year |
| `indicator_id` | str | `"cpi"` |
| `country` | str | ISO3 country code |
| `value` | float | CPI score (0-100) |
| `source` | str | `"public_data"` |

## Used By

`corruption_perception_index` feature — score 0-100 where higher is less corrupt.

See [Public Datasets](/hermes#public-datasets) for the full list of bundled datasets.
