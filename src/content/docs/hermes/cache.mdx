**File:** `core/cache.py`

## How It Works

Every fetch goes through `RawCache.get_or_fetch()`. Data is stored as Parquet files with a sidecar `.meta.json` under `~/.hermes_cache/raw/<source>/<hash>.parquet`.

**Keying:** SHA-256 of `"{source}:{json(params, sort_keys=True)}"`, truncated to 16 hex chars.

**Flow:** Check cache → if miss or expired, call async fetch → store result → return DataFrame.

## Per-Source TTLs

| Source | TTL |
|--------|-----|
| GDELT | 6 hours |
| World Bank | 7 days |
| IMF | 7 days |
| SEC EDGAR | 7 days |
| Finnhub | 7 days |
| OpenSanctions | 30 days |
| FRED | 30 days (per code) |
| Binance | 1 day |
| Yahoo Finance | 1 day |
| Public Datasets | static (no cache) |

## API

| Method | Description |
|--------|-------------|
| `get(source, params, ttl)` | Read cached DataFrame; raises `CacheMiss` on miss/expiry |
| `put(source, params, df)` | Write DataFrame to Parquet with metadata |
| `get_or_fetch(source, params, fetch_fn, force, ttl)` | Try cache first (skip if `force=True`), fall back to `fetch_fn` |
| `clear(older_than)` | Evict entries older than a `timedelta` (supports `h`/`d`/`w` units) |
| `stats()` | File counts by source, hit/miss counts, hit rates |

## Usage

```python
# Force a fresh fetch (bypass cache)
df = await hr.world_bank.fetch("NY.GDP.MKTP.KD.ZG", "USA", 2010, 2024, force=True)

# Check cache health
stats = hr.cache_stats()
# {"files": {"world_bank": 42, "fred": 18, ...}, "hits": {...}, "misses": {...}}

# Evict old entries
hr.clear_cache(older_than="7d")
```
