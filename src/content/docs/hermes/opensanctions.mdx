## What It Does

Fetches sanctioned entities from the OpenSanctions API (`api.opensanctions.org`). Covers multiple sanctions lists: US OFAC SDN, EU FSUK, UK FCDOS, and UN Security Council.

## Fetch

```python
df = await hr.opensanction.fetch(
    country="USA",          # ISO3 country code
    datasets="us_ofac_sdn", # specific dataset
)
```

## Datasets

| Dataset | Description |
|---------|-------------|
| `us_ofac_sdn` | US Treasury OFAC Specially Designated Nationals |
| `eu_fsf` | EU Financial Sanctions List |
| `uk_fcdos` | UK Financial Conduct Department of State |
| `un_sc` | UN Security Council Sanctions |

## Output Columns

| Column | Type | Description |
|--------|------|-------------|
| `date` | datetime | Observation date |
| `indicator_id` | str | Entity type |
| `country` | str | ISO2 country code |
| `value` | float | Sanctions count |
| `source` | str | `"opensanctions"` |

## Used By

- `sanctions_count_active` — total active sanctions for a country
- `sanctions_new_30d` — sanctions added in last 30 days
- `sanctions_sector_coverage` — sector coverage ratio

## Cache

30-day TTL (sanctions lists change slowly).
