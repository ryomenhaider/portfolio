**File:** `hermes/__init__.py`

## What It Does

The `Hermes` class is the single entry point to the entire platform. It composes every connector, the feature pipeline, and the analysis models into one object — all functionality is reachable through one import:

```python
from hermes import Hermes
```

## Constructor

```python
Hermes(
    opensanction_api: str,       # OpenSanctions API key
    new_data_api: str,           # NewsData API key (wired, no connector yet)
    fred_api: str,               # FRED API key
    sec_username: str,           # SEC EDGAR username (for User-Agent)
    sec_email: str,              # SEC EDGAR email
    finnhub_api: str,            # Finnhub API key
    cache_dir: str | None = None,# Custom cache dir (default: ~/.hermes_cache)
    use_cache: bool = True,      # Enable/disable caching
)
```

## Data Source Connectors

| Attribute | Class | Source | What It Fetches |
|-----------|-------|--------|-----------------|
| `.world_bank` | `World_bank` | World Bank v2 API | GDP, inflation, unemployment, governance, debt — 20+ indicators |
| `.imf` | `IMF` | IMF SDMX 3.0 | IFS, WEO, GFS dataflows — PPI, CPI, fiscal balance, REER |
| `.gdelt` | `GDELT` | GDELT Doc API + exports | Conflict, protest, diplomacy events — Goldstein scale, battle deaths |
| `.opensanction` | `OpenSanction` | OpenSanctions API | Sanctions lists (OFAC, EU, UK, UN) |
| `.fred` | `FRED` | FRED (Federal Reserve) | 23 US economic series — GDP, CPI, Fed Funds, VIX, yield curve |
| `.binance` | `Binance` | Binance API | Spot + futures OHLCV, order book, funding rate, open interest |
| `.finnhub` | `FINNHUB` | Finnhub API | 12 endpoints: candles, quote, profile, metrics, peers, earnings, EPS |
| `.sec_edger` | `SECEDGAR` | SEC EDGAR XBRL | Company facts — income, balance sheet, cash flow via XBRL |
| `.yfin` | `Yfinance` | Yahoo Finance | EPS estimate, revenue estimate, earnings history |
| `.datasets` | `PUBLIC_DATASET` | Bundled CSVs | 8 datasets: HRS, HDI, CPI, FSI, NATO, CRS, CVS, SIPRI |

## Analysis Models

| Attribute | Class | What It Provides |
|-----------|-------|------------------|
| `.country_features` | `pipeline` | `get_country_risk_features()` and `build_training_panel()` — 58 country risk features |
| `.ta_feature` | `TAfeatures` | Technical analysis — 86-field `TechnicalSnapshot` from Binance data |
| `.fa_features` | `FAfeatures` | Fundamental analysis — 71-field `CompanyFundamental` from Finnhub/SEC/FRED/YF |

## Feature Registry

| Attribute | Description |
|-----------|-------------|
| `.lf` | Feature groups: `.eco` (economic), `.geo` (geopolitical), `.sec` (security), `.soc` (social), `.env` (environmental) |
| `.list_countries` | All ~250 supported ISO3 country codes |
| `.list_features` | All ~58 feature functions (decorated with `@feature`) |

## Methods

| Method | Returns | Description |
|--------|---------|-------------|
| `.clear_cache(older_than)` | `None` | Evict cache entries older than a timedelta (supports `h`/`d`/`w` units) |
| `.cache_stats()` | `dict` | Files, per-source hit/miss counts, and hit rates |

## Example

```python
from hermes import Hermes

hr = Hermes(
    opensanction_api="your-key",
    new_data_api="",
    fred_api="your-key",
    sec_username="your-username",
    sec_email="you@example.com",
    finnhub_api="your-key",
)

# Country risk snapshot (dashboard mode)
risk = await hr.country_features.get_country_risk_features("USA")
risk["economic"]["gdp_growth_yoy"]

# Country risk panel (ML mode)
panel = await hr.country_features.build_training_panel(
    fns=hr.list_features[:5],
    countries=["USA", "GBR", "DEU"],
)

# Technical snapshot
ta = await hr.ta_feature.get_technical("BTCUSDT")
ta.trend_score

# Fundamental snapshot
fa = await hr.fa_features.get_fundamentels("AAPL")
fa.pe_ratio

# Direct connector usage
df = await hr.world_bank.fetch("NY.GDP.MKTP.KD.ZG", "USA", 2010, 2024)
df = await hr.fred.fetch(["DFF", "UNRATE", "CPIAUCSL"])
```
