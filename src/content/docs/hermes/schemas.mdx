## Connector Output (Standard)

All connectors (except GDELT) return a `pd.DataFrame` with a consistent shape:

| Column | Type | Description |
|--------|------|-------------|
| `date` | datetime | Observation date |
| `indicator_id` | str | Indicator code (e.g. `NY.GDP.MKTP.KD.ZG`) |
| `country` | str | ISO2 or ISO3 country code |
| `value` | float | Numeric value |
| `source` | str | Data source identifier |

## GDELT Event Schema

| Column | Type | Description |
|--------|------|-------------|
| `event_id` | str | GDELT event identifier |
| `date` | datetime | Event date |
| `country_iso3` | str | ISO3 country code (FIPS-normalized) |
| `event_type` | str | CONFLICT, PROTEST, DIPLOMACY, or SANCTIONS |
| `severity` | float | Event severity score |
| `lat` | float | Latitude |
| `lon` | float | Longitude |
| `source` | str | Always `"gdelt"` |

## Feature Output (Dual-Mode)

Every feature function returns different shapes depending on mode:

**`"F"` mode (dashboard):** A single scalar — `float`, `int`, `str`, or `bool`.

```python
await hr.lf.eco.gdp_growth_yoy("USA", mode="F")  # 2.3
await hr.lf.geo.regime_type("USA", mode="F")      # "presidential"
```

**`"ML"` mode (training):** A monthly `pd.Series` with DatetimeIndex, resampled and interpolated.

```python
await hr.lf.eco.gdp_growth_yoy("USA", mode="ML")
# 2020-01-01    2.1
# 2020-02-01    2.0
# ...
```

Missing data returns `np.nan` (`"F"`) or an empty `pd.Series` (`"ML"`) — never raises.

## Training Panel Schema

Output of `build_training_panel(fns, countries)`:

A `pd.DataFrame` with a `MultiIndex(country_iso3, date)`, one column per feature function. Handles deduplication and concatenation across countries.

## TechnicalSnapshot

86-field dataclass for crypto technical analysis (`hr.ta_feature.get_technical(symbol)`):

| Category | Fields |
|----------|--------|
| Price | OHLCV, returns (1/5/10/60-bar), range metrics |
| Moving averages | SMA 20/50/200 distance, EMA 9/21/50 differences |
| Volatility | 20/60-bar vol, ATR-14 normalized |
| Volume | relative volume 20-bar, taker buy ratio |
| Trades | count, buy ratio, avg/median trade size, large trade ratio |
| Order book | bid/ask price/qty, spread (abs/bps), imbalance, depth |
| 24h metrics | high/low/last, range, pct change, position in range, volume |
| Funding | rate, lag-3, change, z-score, time to next funding |
| Open interest | current, 1h/24h changes, OI-to-volume ratio |
| Composites | trend score, mean reversion score, liquidity score, order flow score, sentiment score |

## CompanyFundamental

71-field dataclass for stock fundamental analysis (`hr.fa_features.get_fundamentels(ticker)`):

| Category | Fields |
|----------|--------|
| Filing | ticker, date, period, year, type |
| Income | revenue through net income, EPS basic/diluted |
| Balance sheet | cash, receivables, inventory, assets, liabilities, equity, debt |
| Cash flows | operating/investing/financing, capex |
| Market | shares outstanding, current price, market cap |
| Estimates | EPS, revenue, earnings/revenue surprise |
| Macro | GDP, GDP growth, inflation, interest rates, unemployment, government debt, FX rates |
| Valuation | P/E, P/S, P/B, EV/EBITDA, ROE, ROA, D/E |
