## What It Does

Fetches indicator time series from the World Bank v2 API (`api.worldbank.org/v2`). Covers ~20 indicators across economic, governance, and social dimensions.

## Fetch

```python
df = await hr.world_bank.fetch(
    indicator="NY.GDP.MKTP.KD.ZG",  # GDP growth
    country="USA",
    start_year=2010,
    end_year=2024,
)
```

## Output Columns

| Column | Type | Description |
|--------|------|-------------|
| `date` | datetime | Year |
| `indicator_id` | str | World Bank indicator code |
| `country` | str | ISO3 country code |
| `value` | float | Indicator value |
| `source` | str | `"world_bank"` |
