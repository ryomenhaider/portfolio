## Supported Codes

Hermes uses **~250 ISO3 country codes** (Alpha-3) from the `pycountry` library. Full list accessible via:

```python
hr.list_countries  # ["AFG", "ALB", "DZA", ...]
```

## Validation

```python
from hermes.core.countries import check_iso3

check_iso3("USA")  # True
check_iso3("XYZ")  # raises ValueError
```

## Coverage Notes

Not every source covers every country:

| Source | Coverage |
|--------|----------|
| World Bank | ~200 countries |
| IMF | ~190 countries |
| GDELT | Global (event-level) |
| OpenSanctions | Global (entity-level) |
| FRED | United States only |
| Binance | N/A (asset-based, not country-based) |
| Bundled datasets | Varies (HRS: ~200, HDI: ~190, FSI: ~170, SIPRI: ~170) |

Features that depend on missing data return `NaN` rather than raising.
