## Why from scratch

You don't really understand linear algebra until you've implemented it. That's the bet behind Vecta: a C++17 library that reimplements the chapters of *Mathematics for Machine Learning* (Deisenroth, Faisal, Ong) — from vectors up — with Python bindings via pybind11.

## How it's structured

Each chapter gets a matching folder in headers, sources, bindings, Python package, and both test suites:

```
include/vecta/<chapter>/       C++ headers
src/<chapter>/                 implementation
bindings/<chapter>_bindings.cpp
python/vecta/<chapter>/
tests/cpp/<chapter>/           Catch2
tests/python/<chapter>/        pytest
```

The rule that keeps the project alive: **every chapter compiles, links, imports, and has a smoke test** — even the stubs. Replace `placeholder()` with real code as you study.
